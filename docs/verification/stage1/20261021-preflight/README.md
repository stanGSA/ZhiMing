## 本次发现并修复的执行缺口

1. `draft_week23.py`、`draft_week6.py` 在源文件与模板不一致时拒绝覆盖；一致时不重写文件。审核修订以源文件为准，后续模板变化需明确迁移，不把旧模板回写当作内容更新。
2. 同内容版本的复审否决先撤销旧批准，再检查是否允许新增批准。整批未校准、kappa无法计算或调用未完成不能成为保留旧批准的理由；撤销记录归档为 `ledger_revocations.json`。

4. 真实调用必须明确选择有上限预算或用户授权的无限额配置；预算账本可跨 run / revise / 续跑保留。费用字段为费率估算，不能冒充供应商账单。
