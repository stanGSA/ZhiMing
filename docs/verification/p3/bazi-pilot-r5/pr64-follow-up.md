## 问题与处理

| 审查复现 | 合并时行为 | 修复后行为 |
| --- | --- | --- |
| “8月可以全投而不是观望” | “而不是”使“全投”被删除，零修复提交 | 全投作为独立动作检查，被否定的是观望，交易推荐要求修复 |
| “8月不要追涨而要分批买入” | 对追涨的限制豁免了买入 | 分别判断两个动作，不能把前一个动作的否定借给后一个动作 |
| “八字不能预测收益所以8月适合小额度试探” | 免责声明豁免整个分句 | 拆分连接的命题，每个交易动作单独判断；同句免责声明不豁免推荐 |
| “8月先核实你的可投入资金和风险承受能力” | 因“投入”一词误拒、消耗修复 | 财务条件核实直接放行；“核实后可投入资金”仍拒，避免把实际投入误当核实 |
| “不能说八字能决定8月是否加仓” | 单凭“不能说”判反向否定，误拒 | 区分否认能力与否认无能力；“不能说八字不能决定……”和双重、弱化否定仍拒 |
| “下个月适合加仓” | 缺时间锚，零修复提交 | 复用现有相对日期词表，补充具体年份和完整日期，要求修复 |

不再对整段批量删除全投用语，也不再仅凭任意位置出现约束词就放行全部交易动作。只有裸并列列表可继承同一约束，例如“不要加仓、买入”；“不要追涨而要买入”是两个动作判断。事实表、原有起运/柱角色/重复文本检查保持原逻辑。

依 PR #64 已记载的边界，“八月不宜加仓”等只收着的表达继续放行；“最忌错过加仓时机”“不宜犹豫地加仓”等否定等待而鼓励交易的表述仍拒。提示词和修复提示同步使用这一口径，保留核实财务条件的提醒。
