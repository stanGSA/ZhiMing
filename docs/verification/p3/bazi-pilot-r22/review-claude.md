## 6. r23 的改动（本 PR）

### 6.1 修两处误拒

- **交易规则**（`pipeline/bazi.py`，`SUITABILITY_DENIED`）：
  - 放行：“不等于 / 不代表 / 不意味着”紧接“适合 / 宜 / 值得 / 该”时，视为否定适合，例如“不等于适合重仓”“这不代表适合加仓”。
  - 仍拒：“不等于不适合重仓”（转回限制）、外层否定（“不能说不等于适合”）、双重否定（“并非不等于适合”）、弱化（“不一定不等于适合”）、转折后再推荐（“……但可以加仓”“而是更适合加仓”），以及“适合”不紧挨交易的情形（“不等于适合很多人的重仓”）。
- **确定性规则**（`common/output_policy.py`，只补识别缺口）：
  - 放行：“对……”之外，“遇到 / 碰到 / 遇上 / 听到 / 面对”带引号的“稳赚”说法、后面接核实或追问时，也算质疑；“多问”可以带“几个为什么”。
  - 仍拒：不带引号、“就跟进”、“不用多问”、外层否定、“多问几个为什么是多此一举”、后面又写“这次确实稳赚”。

### 6.2 换运目标按序列核对（`HANDOFF_TARGET`，在 `cycle_role_problems` 里）

“换 / 交运 / 换运 / 交接 / 换成”，或“进入 / 转入”后接“下一步、第 N 步、某柱”的说法，按下面两条核对：

- 后面接年、月、日、时柱时拒，提示“年、月、日、时柱不随换运改变”，并给出那一步实际的大运。
- 带年份或步数、后面接的干支又不是那一步时拒，例如“2033年交运到辛酉”“换到第5步大运辛酉”。

不带年份、步数和柱名的不检查（如“进入丙午年”）。否定从动词前判断：“不是换月柱乙卯”放过，“并非不换成月柱乙卯”仍拒。

### 6.3 时点之后的流期（`after_point_findings`，计时题的每一层正文）

分句开头的时点（“立春之后 / 2月4日起 / 5月起”，前面可以带“从”）管到下一个时间词或分号为止。管辖范围内点名的流年、流月（含它们的冲合刑害）如果整段都在这个时点之前，就拒。

- 时点日期的取法：
  - 立春取所问范围内寅月的起始日；
  - “X月X日起”取当天，流期结束在当天或更早都算“之前”；
  - “X月起”取 1 日，流期须在 1 日前就已结束。
- 放过：
  - 括号里的日期不当作时间词；
  - 写明已结束的不拒（接替、走完、结束、不再……）；
  - “此前 / 之前 / 以前”结束管辖范围；
  - 句中谓语里的时点不算，例如“流月乙未……从7月7日起把压力感带进来”。

### 6.4 已过去且在所问范围外的时段（`past_time_findings`，计时题）

摘要、正文、建议、收尾里写“今年上半年 / 下半年 / 年初 / 年中 / 春天 / 夏天 / X月（到Y月）”，而这段时间整段已经过去、也不在所问范围内时，就拒。

- 放过：所在分句是回看（回看、复盘、已经、以来、此前……）的。
- 所问范围内已经过去的月份（比如问“今年下半年”时写的“今年7月”）不受影响。

## 9. 已知局限

- 时点检查只看计时题每层正文分句开头的时点：
  - 摘要和建议里的时点不查；
  - 时间词只认月、日、立春、旬和上下半年，“过年后”“春节后”这类不认。
- 已过时段只认“今年……”，“去年”和具体年份不在内。回看词列得比较宽，含“已”“曾”，少数写在回看分句里的错误会放过。

- 交易误拒的放行，要求转折词紧贴“适合”，“适合”又紧贴交易；其他语序仍按原规则判断。
- 这些检查和以前一样，靠的是句式加上计算结果核对，不能保证覆盖所有中文写法。
