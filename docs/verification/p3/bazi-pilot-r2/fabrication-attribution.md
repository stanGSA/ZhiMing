# r2 编造分类及争议

分类由 Codex 根据保存的计算事实、最终回答和原始评委理由离线整理，**不代表负责人或独立人工裁定**。所有原始布尔分数保持不变；分类描述的是失败指控的种类，包含下表明确标出的争议。

| 组别 / 样本 | 分类 | 核对结果 |
| --- | --- | --- |
| single 下个月事业 #1 | 事实类 | **评委指控错误。** 评委称 2026 应为丙戌，但实际 `current_candidates` 是丁亥（2018–2028），丙戌从 2028 开始。回答的丁亥与计算相符。为可追溯性保留原失败及其事实类指控，不静默改为通过 |
| single 文字出生 #3 | 叙述类 | 写“已有伴侣的，可能为分配不均而不痛快；单身的，可能遇到竞争对手或第三方意见”。评委认可其有条件含义却要求“如果你正在”的明确形式；与允许条件场景的尺度存在争议，保留原失败 |
| pipeline 大运 #1 | 叙述类 | “如果你回看童年到青少年阶段，可能有一段比较爱问‘为什么’的时期，或者在家里、学校里更愿意自己拿主意。”评委认为补充未提供的个人历史。原句确有条件/可能限定，尺度待人工复核；保留叙述类失败 |
| pipeline 投资 #1 | 事实类 | 降级模板取通用释义的前三个关键词，把“甲己合”附到丙辛、丁壬具体关系之后。计算的相合关系本身正确，附加表述错配可从保存的释义与代码复现，见 [fallback-probe.json](fallback-probe.json) |

投资 #1 的原评委同时称乙巳、戊申、己酉等流月不存在，实际这些干支存在于 2027 年流期；又称没有投资风险提示，实际最终回答含“这不构成投资建议；涉及大额资金请结合自身财务状况，必要时咨询持牌专业人士。”。这些理由不成立，但通用关键词绑定、截句和失去针对性的问题独立存在，不能据此全盘撤销失败。

[fabrication-reviewed.yaml](fabrication-reviewed.yaml) 是传给统计工具的分类输入；工具的字段名 `reviewed` 沿用既有接口，并非说明已完成人工确认。[fabrication-counts.md](fabrication-counts.md) 中 pipeline 的“完整”只表示已提交的 18 条均有原评分且 2 条指控均已分类，不表示评委无误。single 的已提交回答仍有 9 条未评分，所以两组计数尚未完整，不能把观测到的 1 条事实类、1 条叙述类当成 single 全部发生数。
