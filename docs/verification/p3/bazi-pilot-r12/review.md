### 3.2 已知放过

**大运 #2（事实类）**

> 走完前几步之后，第4步大运己未（2023年交运，2033年换下一步）说明你现在处在第4步大运己未，……前一步是第3步戊午（2013年交运），下一步是第5步庚申（2033年交运），也就是说你目前正走在这十年的中段偏后位置。

| 写法 | 计算结果 |
| --- | --- |
| 2026 年在这十年的“中段偏后” | 起运 1993-02-10，这步大运 2023 年交运；2026-11-12 是第 4 年，约 3.8 年，在前半段 |

根因：事实表给了当前大运和交运年份，没给今天在这步大运的第几年，写作者自己估算；没有检查核对“这十年的前 / 中 / 后段”。评委 time_consistent=false 指出了这一点，no_fabricated_facts=true，计数表里不计编造。按可核验事实写错，计**事实类**，与负责人一致。r2 大运 #2 的“你现在正处在这一运的中段偏后位置”也是同一错误，当时同样放过（§5 的重放）。

**投资 #3（交易边界）**

> 三、4月5日起到8月8日前后：起伏与拉扯多，克制优先
> ……把这些合起来看，这几个月更像“情绪和消息面都容易起波澜”的阶段，不适合因为一时冲动或他人鼓动就把积蓄全数投入。如果你正在做资金安排，建议分批、留应急金，并和伴侣或家人把边界讲清楚。

与 r8 投资 #1“把‘全投’换成‘分批、留底、按预算’更稳妥”（负责人定为不算放过）相比，这句有推荐词“建议”，并且落在有起止日期的一层里；r8 复核里拒得对的“明年更适合小额、分批、有明确止损的尝试”也是有时间、有推荐词。交易检查只认带交易动词的动作，“分批”省略了动词，句子本身也没有时间词，所以放过。**负责人 2026-11-12 决定：算已知放过，r13 补拒。** 评委四维全 true，原分不变。

| 关系检查：普通词里的“合 / 冲 / 刑 / 害 / 破”（`COMPOUND`、`relation_char`、`RELATION_LOOSE`） | 关系字在“配合、适合、结合、合作、缓冲、冲动、刑事、利害、害怕、突破、破产……”这类普通词里时不算关系；窗口继续往后找真正的关系词（“配合顺利并且相合”照拒）。只有普通词的句子不算断言关系，但同句后面的分句又写出关系（“不是配合松动，而是相合”）照拒。`relation_reasserted` 同时认外层否定（“不能说不相合”），后一分句里的“配合”也不再当成合 |
| 大运位置（`STAGE_POSITION`、`position_problems`） | “这十年 / 这步大运 / 这一运 / 当前大运 / 己未大运……”后接“前半段、中段、中段偏后、后半段、尾声……”或“第 N 年”时，按今天离交运的年数核对：位置用宽松的十分区间（中段 0.3—0.7，中段偏后 0.5—0.8，后半段 0.5—1……），第 N 年允许 N 为已过年数或其加 1。交运年（当前大运两个候选）不核对；其他大运的位置（“前一步戊午大运的后半段”）不核对；否认错误的放行，否认正确的照拒 |
| 上下文写明位置（`Bazi.context`） | 当前大运唯一时加“今天（2026-11-12）在当前大运己未的第4年（2023年交运，2033年换下一步），属于这十年的前半段；写这步大运走到哪里时照这个写。” |
| 标题：月份接季节或年段（`LINKED_END`、`linked_end`） | “X月（日）（以后）到 / 至 夏季、入夏、初秋、上半年、年中……”读成一段，从 X 月到所接时段的末尾；“入 / 初 + 季”取该季第一个月。中间隔了逗号的不连读。“秋季到年底”从秋季开始，不再从年底开始 |
| 交易检查：省略动词的分批推荐（`BATCH_RECOMMENDED`、`batch_recommended`） | 推荐词（建议、适合、可以、最好、不妨、应该……）带出“分批、分次、分几次、分几批、定投”，没有否定或约束管着，句内有时间词，或者所在一层的标题写了时间，就按推荐投入节奏拒。“定投资纪律”不算定投。没有推荐词的“换成分批更稳妥”、没有时间的建议仍放行 |

题集、rubric、评委配置、`*_final.yaml` 都没有改；共用规则没有改；既有测试一条没改。
