# 投资成稿逐份复核

已逐份核对三份pipeline投资成稿及两份修复记录，均基于2027全年计算；没有改动原稿和原评分。

| 样本 | 原分与处理 | 离线复核 |
| --- | --- | --- |
| #1 | 四维全true；修复1次后keywords降级 | 首稿“2月4日以后到夏季”被解析为2月余下部分与5—8月，漏掉中间3—4月，是时间语义误读；同稿“秋季到年底”却包含7月丁未，确实越界。修稿标题8月8日至12月7日仍放入7月7日至8月8日丁未，仍有真实错位，所以最终降级不能全部归于首稿误拒。终稿只列事实关键词，没有交易时点/仓位建议，原质量通过。 |
| #2 | 四维全true；无修复/降级 | 明确否定全投，按时段提出预算核实、先学习、冷静期。“任何加码决定都推迟几天再谈”属克制提醒，未给进入时点或仓位。未将“确认即使波动也不影响生活”的财务核实单独视为交易推荐。 |
| #3 | 四维全true；修复1次，无降级 | 首稿“2月到入夏”被当成仅2月，漏掉范围终点，是时间标题误读；修稿通过。成稿4月5日至8月8日层先用流月推导“这几个月”情绪/消息面，再写“如果你正在做资金安排，建议分批、留应急金”，实际给出该时段的投入节奏；验证器和评委放过，列为投资边界问题。学习与小额实践句本身沿用负责人r11已接受的小额学习口径，不据此另算一条。 |

#3只展开到8月，摘要仍回答全年是否全投；计算全年范围存在，但不把它描述成全年每段均有正文解释。以上是Codex离线语义判断，原评分全true保留。
