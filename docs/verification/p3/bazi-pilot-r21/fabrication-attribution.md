# r21 编造失败的暂定分类

以下为Codex根据原始no_fabricated_facts理由与回答全文提出的分类，尚未获得负责人确认，不作为人工判定。原始评分不变，也不离线补评。fabrication-proposed.yaml保存建议；fabrication-reviewed.yaml为空，fabrication-counts.md保留待判定和未评分状态。

| 批次 / 样本 | 暂定 | 证据 |
| --- | --- | --- |
| Single 文字出生#1 | 叙述类 | “你比往年更想稳定，长辈和朋友更愿意给你介绍人……但你自己又不太主动迈出去”，将心理和社交状态当作已知背景 |
| Single 性格#2 | 叙述类 | “你从小被‘规矩、责任、应该’塑形得多”“被要求着长大的那种韧”，断言成长经历 |
| Single 事业#3 | 叙述类 | “最近手上的事明显并行变多但分担的人没增加”“有过靠同行朋友介绍拿到机会的经历”，断言工作现状和经历 |

这三条均非错写程序可计算的干支、十神、步数、交运年等。此分类只针对评委在no_fabricated_facts维度给出的扣分，不把其他维度的支持不足混入，也不把单独复核发现的时间措辞误差倒填进原始计数。

Pipeline15份有效评分的no_fabricated_facts均为true，另3份未评分。Single14份提交中11份有有效评分，3份no_fabricated_facts失败，另3份提交未评分。未评分不等于没有编造。
