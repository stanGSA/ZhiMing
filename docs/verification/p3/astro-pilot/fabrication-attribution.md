# 编造分类依据（离线复核）

分类由 Codex 对照评委理由、原句和计算事实完成，不是独立人工裁决；评委失败仍按失败保留。分类表的“完整”仅表示已评分失败都有类别，不表示完成了人工校准。

- `Astro-single / astro_pilot_trait#1`：事实类、叙述类。评委同时指向“土星同时与木星、与（第1宫）木星形成三分相”的宫位／相位附加表述，以及“你对‘家、内在根基’有自己想改造的版本”的经历式断言。重复写法是否构成错误事实存在争议，仍按评委理由指向的可核验事实记录事实类，不将失败改判为通过。
- `Astro-single / astro_pilot_trait#2`：叙述类。评委指向“你可能有过这种体验……”和“你的自我价值感往往来自……”；没有指控出生信息、落座、宫位等计算事实错误。“可能”及本命性格语境是否已充分表明推测，存在评分边界争议，保留原分。

本批36行全部评分，已提交回答中的三条编造失败均已列出类别；计数见 fabrication-counts.md。

- `Astro-pipeline / astro_pilot_unknown_time#3`：叙述类。评委指向“生活中你往往先注意到各方立场，习惯在表达前掂量措辞……”和“你容易在团队支持、资源稳定这类事上体察到别人忽略的细节”，将象征推理写成用户已有行为；未指控出生信息、落座、宫位或日期错误。性格题对倾向与行为断言的评分边界仍有争议，保留原分。
