# 编造失败分类依据

分类由Codex离线阅读原回答、原始评委理由和计算事实完成；不是负责人逐条裁决或独立人工校准。
原始布尔评分不变，只拆分已提交回答中`no_fabricated_facts=false`的失败。
其他维度的支撑不足、时间失败不额外算作编造。事实类指控有异议时保守保留，并在下表说明；
不能将计数理解成全部被指控事实均已独立验证为错。
