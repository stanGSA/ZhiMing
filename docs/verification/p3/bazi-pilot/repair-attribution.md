# 八字调参集修复复核

18条pipeline中3条触发修复，各增加1次模型调用，均一次修好、正常提交、质量通过，未降级。
以下依据实际渲染稿及trace中的repair引句，不把候选句误称为已证明的错误。

| 样本 | 检查与实际引句 | 复核 |
| --- | --- | --- |
| 大运概览第2次 | “传统上偏财这类标签对应的不是‘必然发财’，而是探索机会时先核实成本、不据符号做投资预测。” | **误拒**。句子否定必然结果，通用确定性规则仍匹配“必然”。引句定位准确，问题判定错误；修复成功，未造成失答或质量失败。 |
| 大运概览第3次 | “年柱年柱戊辰（天干戊为正财）带正财色彩，月柱月柱乙卯（天干乙为比肩）带比肩色彩，时柱时柱己卯（天干己为偏财）又见偏财。” | **真实重复**。3个问题都指向同一条渲染句，修复后重复消失。 |

合计6条检查问题、3次修复调用：1条为否定确定性表述的误拒，5条为重复标签。
全部引句都能在对应被拒稿中找到。误拒并未造成降级，但浪费一次调用；应与2次正确拦截区分。
