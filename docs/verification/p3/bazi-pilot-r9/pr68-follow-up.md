# PR #68 合并后修复

PR #68 已合并到 `claude_modify_model`（`0ebbe4c`）。本次修复复核发现的四类规则问题，不调用付费模型，不改题集、rubric 或原有实验结果。

| 问题 | 复现 | 修复 |
| --- | --- | --- |
| 无关分句的否定评价放过交易推荐 | “8月适合加仓；外出旅游不太合适。”原先直接提交、没有修复 | 交易否定评价在中英文分号处停止；评价前的宾语和视角文字也不能跨过分句边界 |
| 双重否定、程度词被当作确定劝阻 | “8月加仓不是完全不合适”“并不是那么不合适”“不算不合适”“未必很不合适”原先放行 | 评价的外层否定允许程度词组合；“完全不合适”“根本不适合”仍放行 |
| 时间否定句带介词时被误拒 | “不是在春节之后进入流年丁未，而是在立春”“不是在下旬之后进入流月庚子，而是在12月7日” | 先识别时间边界前的“在／要到／等到”等，再沿用已有否定判断；外层否定、双重否定、程度词守卫仍须拒 |
| 查询区间起点被当成流月起点 | 查询 2026-12-20 至 12-31 时，正确的“12月上旬起进入流月庚子”被要求改为“12月20日起” | 从计算器同一组物理节气取真实起点，再转换到查询时区；不改变计算结果中用于展示的截断区间。跨年查询可以核对上年12月开始的流月 |
