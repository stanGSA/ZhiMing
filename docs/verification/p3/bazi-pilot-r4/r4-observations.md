- 12 条时机题的分段标题无检查命中；旧标题“先甜后磨的上半年尾巴”离线探针仍拒，引用里的否定句仍放行。

- 海外3次均只追问1次，出生固定 UTC+8 与洛杉矶咨询时区分开；文字出生3次均0追问且资料匹配；计算时间范围检查全部通过。这不代表所有自然语言时间解释都正确。
- 0 降级，没有真实降级链覆盖；不能用空 fallback-probe.json 宣称该链已验证。
- 与 r3 比，pipeline 原质量16/18→14/18，修复4→1，降级0→0，最多调用2→2。这是小样本描述，6题各3次，同模型运行和评分，不作显著性或因果判断。

本轮结论：不冻结，不运行 final，不重评失败；后续应先复核评委事实来源争议，并处理已知起运叙述错误及流期投资策略问题。
