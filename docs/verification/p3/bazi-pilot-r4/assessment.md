pipeline 四条原质量失败：投资 #1（supported、fabricated）、大运 #2（fabricated，事实来源误读争议）、投资 #2（time、supported）、性格 #3（supported）。大运 #2 引用的起运日、日主、当前大运均来自 calculated_facts，正文还有“按排盘口径”，不能把评委理由当成已核实的事实编造。唯一修复为大运 #3 的“年柱和时柱都带正财、偏财的性质”，最终改为年干正财、时干偏财，2 次调用后质量通过。原句可作集合式概括理解，触发有歧义，不将它武断计为确认事实错误或确认误拒；本轮未观察到因误拒造成降级、失答或质量失败。该修复没有纠正“出生当年起运”，说明修复后通过仍可能含事实错误。详见 repair-attribution.md 与 r4-observations.md。
