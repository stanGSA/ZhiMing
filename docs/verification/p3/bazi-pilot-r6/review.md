## 3. 归因

### 3.1 交易检查的误拒与降级

我取 [repair-evidence.json](repair-evidence.json) 里投资题被拒草稿的全文，在 `66c6bd5` 的 worktree 里逐句交给 `Bazi.trade_problems`。触发交易问题的共 9 句，**全部是保守说法**：

| 样本 / 稿 | 原句 | 类型 |
| --- | --- | --- |
| 投资 #1 第 1 稿 | “这些流月只作节奏参考，不构成买卖时点。” | 否定时点 |
| 投资 #2 第 1 稿 | “明年整体不算适合把积蓄全投进股市的一年……” | “不算适合”否定全投 |
| 投资 #2 第 1 稿 | “建议这段时间把‘决定’放慢，涉及大额投入的事多找人复核。” | 动作后提醒复核 |
| 投资 #2 第 1 稿 | “整体看，明年不像是适合一把投入的年份。” | “不像是适合”否定 |
| 投资 #2 第 1 稿 | “明年更适合先稳住节奏、看清风险，再谈投入多少……” | 先稳住、再谈投入 |
| 投资 #2 第 2 稿 | “明年整体谈不上是让人放心全押的一年……” | “谈不上”否定全押 |
| 投资 #3 第 1 稿 | “明年整体不算适合把积蓄全部投入股市的年份……” | “不算适合”否定全投 |
| 投资 #3 第 1 稿 | “……合伙或跟风操作尤其要边界清楚。” | 动作后提醒边界 |
| 投资 #3 第 1 稿 | “……给自己设一个冷静期再决定任何投入。” | 冷静期后再决定 |

误拒的原因有三类：

1. **否定词识别不全。** “不算 / 不像是 / 不构成”没有当作约束；“不算适合”里的“适合”反而被当作鼓励。
2. **外层否定误判。** `TURNED_BACK` 把“谈不上”一律当作外层否定，但“谈不上是让人放心全押”后面没有再接否定，“谈不上”本身就是否定。
3. **后置提醒不识别。** 动作后面跟“复核 / 边界清楚”的提醒，或“冷静期再决定”的延后，都不认。

对 B 的影响：投资 #2 第二稿被拒的只有这一句，随后降级为关键词稿，质量 supported_conclusion 判失败。这是**造成降级的可定位误拒**。

- 负责人把这句改写为核实财务后，问题列表为空（supplemental-checks.json 的 terminal_false_rejection_probe）。我同意这一判断。
- 这不证明原稿本来能通过质量评分：原稿还把年初丙午的地支冲写到了年柱上，而计算里是月柱。

另外两条投资修复（#1、#3）最终没有降级。#1 的修复还有 3 处真实的重复标签。
