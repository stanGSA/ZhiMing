# r3 编造评分失败的离线归因

保留原始 no_fabricated_facts=false；Codex 对原答案、原理由和计算资料离线分类，没有修改分数、补评分或独立人工裁定。分类单位是已提交且该维度失败的回答，一条可同时计入两类；事实类与叙述类不是两个新评分维度。

| 样本 | 离线类别 | 可定位依据 |
| --- | --- | --- |
| single 文字出生 #1 | 叙述类 | “正缘星在2027年才正式登场”“通过朋友介绍、聚会……重新走热一段关系”：将符号写成具体关系前景 |
| single 投资 #1 | 叙述类 | “明年常出现这样的画面……有人拉你合伙、有亲戚朋友开口、有大额消费或换车换房的念头”：具体现实场景近似预言；评委把一般仓位提醒也归入编造的部分有争议，保留原失败 |
| single 文字出生 #2 | 事实类、叙述类 | “这个月偏印当令”实际丙申月为正印；7 月“流月天干与你的日主相合”实际乙与月干庚合。另有“容易遇到有存在感的人”“年底容易有明确的靠近或重新连接”等具体关系预言 |
| single 事业 #3 | 叙述类 | “子水、亥水……补上了这一块，意味着冷静盘账、按流程走的能力这个月是加分的”：把数量/传统符号写成现实能力结论；不是计算出的能力值。原 no_fabricated_facts 理由的尺度可能与 supported_conclusion 重叠，分类记为叙述类，原分保留 |
| single 文字出生 #3 | 叙述类 | “你身边不缺口头上说喜欢的人，甚至暗恋、暧昧也有”：将具体人际经历写成已知事实；还有未来关系推进的断言 |
| pipeline 文字出生 #2 | 事实类 | “但1997年12月28日起运，首步大运辛巳（1997年交运）这个大运阶段需要你留意自身节奏”：把历史首运放入当前半年的说明；当前候选是癸未（2017–2027），不是辛巳 |

single 文字出生 #2 的事实错写主要在原 supported_conclusion 理由中指出，而 no_fabricated_facts 理由着重叙述场景。这里结合原答案和计算事实将同一条编造失败归到两类，未把初筛关键词当成判决。相反，pipeline 的大运阶段指控与实际保存的句子、current_candidates 一致，能够定位。

结果：single 已提交 15 条、15 条评分、5 条编造评分失败，事实类 1、叙述类 5；pipeline 已提交 18 条、18 条评分、1 条编造评分失败，事实类 1、叙述类 0。两组分类表在本次离线归因口径下完整；不等于独立人工审核完成，也不证明未被评委标记的回答没有问题。pipeline 投资题仍有支撑尺度问题，见 assessment.md。

时间维度的布尔值/理由矛盾单独保留，不将其改成新的质量通过率。pipeline #1 的“戊午年”是评委理由里的错误，不能算到模型答案；“28 条计算事实”是代码生成的证据条数提示，评委的附加指控没有使 no_fabricated_facts 变为 false，不新增一条编造计数。

分类输入见 [fabrication-reviewed.yaml](fabrication-reviewed.yaml)。工具列名“待人工判定”、参数 reviewed 沿用仓库接口，不表示独立人工背书。全部原句、完整理由见 [quality-reasons-with-answers.md](quality-reasons-with-answers.md)，大运校验复现见 [known-escape-probe.json](known-escape-probe.json)。
