**推断（未验证）：** 撰写提示词里有两条规则方向相反。

- 一条要求“正文先说生活中的表现”。流水线的 `TAROT_SYSTEM` 和 single 的 `WRITING_RULES` 都有这句。

这条推断和数据一致（新增失败集中在三张牌阵的时机题和关系题），但 r2 没有能检验它的对照。

## 4. r2 新发现的两种已知误拒（只出现在 single）

负责人在 analysis.md 里记了 single 投资题的确定性拒绝，原稿句子形如“不是预言你必定亏钱”“提示的重点不是‘你一定会亏’”。我在当前代码上离线复现，确认它们被拒，原因有两个：

| 句式 | 被拒原因（`common/output_policy.py`） |
| --- | --- |
| 这张牌**不是预言**你必定亏钱 | `NEGATED_FRAME` 只认“不/并不……”**紧接**框架动词（“不预言”），“不是预言”中间多了一个“是”。按 `COPULA`（“不是”）处理时，后面的“预言你”既不是以代词开头，又在中心词之后另起“你”，被当成第二个子句 |
| 重点**不是“你**一定会亏” | `COPULA` 之后要求以代词或指示词开头；开头是引号，`SUBJECT_START` 不匹配 |

去掉“是”（“这不预言你必定亏钱”），或者去掉引号（“重点不是你一定会亏”），现在都能放行。

**影响：**

- single：4 次拒绝落在 2 次投资问答，其中 1 次停在 `retry_limit`，未提交。
- 流水线：r2 没有触发。但按 analysis.md 5.4 的表，高风险问题上，如果两稿都写了这类句子，整篇会被替换为安全模板。

**本 PR 的处理：** 只在 `tests/validation/test_negation_and_dates.py` 加了 4 条严格 xfail（两种句式各 2 条），另加 2 条正例，固定“去掉‘是’或去掉引号时已放行”。规则不改，原因如下：

- 改规则就是 analysis.md 5.4 的选项 C，负责人当时选的是 A；
- r2 的 `degraded="safety"` 为 0，A 的观察结果不支持改；
- 共用校验一改，同批 single 也会变，最终验收集测到的就不再是 r2 的代码。

**请负责人在 P1 结束后决定**：是否另开 PR，把这两种句式纳入否定作用域。改动范围窄，“不是”加框架动词复用 `NEGATED_FRAME`，引号在主语判断前剥掉，原有反例照样要拒。

## 5. 是否继续调参：不需要

1. **r2 预演达标，剩下的不是 P1 的通过条件。** P1 四条预演条件两轮都满足；拆分类别后的 §5 硬性目标（可核验事实 0、叙述编造不高于同批 single）由 r2 确认。没达到的只有叙述编造的争取值。
2. **调参集难以分辨这个指标的变化，继续调有过拟合风险。** 8 题×3 次，同题重复彼此相关，且同一模型评分。
   - 参考计算（按独立二项观测，忽略题内相关性，不是处理相关性后的区间）：
     - 6/24 的 Wilson 95% 区间约 12.0%～44.9%；
     - 第一轮 3/21 对 r2 6/21，双侧 Fisher p≈0.45。
   - 这些数字只说明小样本下差异难以分辨，不证明变化来自噪声，也不证明哪条规则有效或无效。
   - 24 条里失败不超过 2 条，只表示样本比例 ≤10%，不等于统计上证明真实比例 ≤10%。
   - 在这个集合上反复改提示词，容易拟合到这 8 题。最终验收集就是为了检验泛化，所以应当冻结后再检验。
3. **上一轮的定向规则没有带来可观察的改善。** `SCENARIO_RULE` 针对叙述编造，但本批编造失败数没有下降。因为没有隔离它的效果，不据此判它无效。第 3.1 节的推断指向写法指令本身，那是共用规则。
4. **这个根因不属于塔罗。** “正文先说生活中的表现”在 single 的 `WRITING_RULES` 里也有，八字、占星、解梦都要用。只在塔罗提示词里改，等于在流水线内部再写一份规则，正是 D2。计划 P4.2 要逐句审计提示词，把“表达类”规则统一管理，P3 的 60 题集按 §5 正式衡量。这一条应带进那里：
   - P2 的解梦撰写提示词风险最大，因为把梦写成用户经历本身就是这一类错误；
   - P2 起，每个体系单独报告叙述编造占比。
5. **流程上已经没有可调的失败。** r2 的流水线没有修复、降级、回退、工具错误、`retry_limit`、步数或预算失败。

**风险：** 冻结后，最终验收集（各 18 条）仍可能因为样本波动不满足“质量通过率 ≥ 同批 single”。按计划，那时回到调参，不改验收集。
