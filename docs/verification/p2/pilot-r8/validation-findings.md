## 1. 可定位误拒：掉牙过程中的“是……的”复述

对象：Dream-pipeline / `dream_teeth_falling#1` 初稿；修复一次后成功提交，没有降级，最终四维评分通过。

用户原文：“昨晚梦见牙齿一颗一颗掉下来，醒来心里很慌。”实际计算命中“掉牙”，依据和命中短语均来自本轮实际计算，没有新增意象。

原稿片段：“梦里牙齿是一颗一颗掉下来的，不是一下子全没，这个缓慢的过程可能让你在梦里眼看着却拦不住，醒来才会慌。”

被拒原因：“牙齿”不是本次命中的意象，不能解读。

用该题实际命中和本轮知识库作最小回放：

| 文本 | 当前校验 |
| --- | --- |
| 梦里牙齿一颗一颗掉下来。 | 放行 |
| 梦里牙齿是一颗一颗掉下来的。 | 拒绝：“牙齿”不是本次命中的意象 |
| 梦里牙齿象征财富。 | 仍拒绝，保留独立解读牙齿的守卫 |

第二句只是第一句的“是……的”复述，没有把“牙齿”单独作为新的象征解读。误拒可缩小到一句无释义、无心理推断的文本，因此不能仅因完整初稿还包含其他表达，就忽略这个缺陷。

根因：`plugins/dream/match.py::NORMALISATIONS["掉牙"]` 没有覆盖插入“是”的受控构式。`plugins/dream/validation.py::OUTPUT_NORMALISATIONS` 复用它绑定输出，绑定失败后，`ungrounded` 将“梦里牙齿”识别为独立的“牙齿”实体，并触发未命中检查。这是既有归一化范围遗漏，本轮观察到了它；未据此宣称是 PR #50 新引入。

本轮不修改被测源码。按“没有可定位校验缺陷”的 B 条件，这个已重现问题足以阻止冻结；最终提交质量通过不能抹掉前稿误拒。

## 4. 可定位误拒：否定保证及“别把……当成”

`Daily-pipeline / daily_today_general#2` 初稿写：“这些只是象征性的节奏提示，不是事情必然顺利的保证”。全文仅此处出现“必然”，却被拒为确定性说法。`daily_lucky_color#3` 初稿写：“别把配合当成必然有利”，也被相同规则拒绝。两条各修复一次，最终提交且四维评分通过，没有降级。

最小对照：

| 文本 | 当前确定性命中 |
| --- | --- |
| 不是事情必然顺利的保证。 | 必然（误拒） |
| 不代表事情必然顺利。 | 无 |
| 别把配合当成必然有利。 | 必然（误拒） |
| 不代表配合必然有利。 | 无 |
| 事情必然顺利。／配合必然有利。 | 必然（仍应拒绝） |

根因在 `common/output_policy.py::negates_claim`：普通“不是”后接主语时受 `SUBJECT_START` 限制，“事情”不在代词／指示词入口内；`NEGATED_NOUN` 的“别把……当成”宾语也限于既有枚举，没有覆盖“配合”。否定保证的后置中心词“保证”未被前向检查利用。两句都在否认肯定结论，本轮将其记为可定位的否定作用域遗漏，不改产品源码。

## 5. 可定位误拒：否定“稳赚”中的状语插入

`Daily-pipeline / daily_investment_risk#2` 两稿唯一“稳赚”分别在：

- “别在情绪顺畅时把配合或行情当成稳赚。”
- “别因为情绪顺畅就把配合或行情当作稳赚。”

两稿都明确劝阻将行情视作稳赚，仍被 `hard_claim` 命中；一次修复后转 safety 降级，最终评委判 direct_answer、supported_conclusion 不通过。第一、三次投资回答没有发生该修复或降级。

`daily_lucky_color#3` 初稿还有“别把‘有机会’直接当成‘稳赚’”。它在“必然”之前未作为首个报错展示，但离线回放也命中 `hard_claim`，应与已记录的首个错误区分。

| 文本 | 当前 hard_claim |
| --- | --- |
| 别在情绪顺畅时把配合或行情当成稳赚。 | 稳赚（误拒） |
| 别因为情绪顺畅就把配合或行情当作稳赚。 | 稳赚（误拒） |
| 别把配合或行情当成稳赚。 | 无 |
| 别把“有机会”直接当成“稳赚”。 | 稳赚（误拒） |
| 别把“有机会”当成“稳赚”。 | 无 |
| 这笔投资稳赚。 | 稳赚（正确守卫） |
| 别把配合当稳赚，但这笔投资稳赚。 | 稳赚（正确守卫） |
| 不是不把顺手当稳赚。 | 稳赚（正确守卫） |

`GAIN_DISMISSAL` 要求否定词直接连接“把／将＋受控宾语＋谓语”，未覆盖否定词与“把”之间的状语，也未覆盖宾语与谓语之间的“直接”。这仍属于负责人已放行的明确否定“稳赚”语义。本轮只记录边界，没有通过放宽任意文本来绕过守卫。

最终结论：r7 指定原句回放已通过，但新的自然表达仍暴露遗漏；掉牙复述、普通确定性否定、否定“稳赚”三类缺陷独立阻止 B 冻结。不把新观察自动归因于 PR #50 新增代码。下一轮修复应分别增加这些真实原句与肯定、转折、双重否定守卫，再另开实验，不能回写本轮结果。
