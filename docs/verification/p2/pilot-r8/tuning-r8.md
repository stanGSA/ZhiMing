## 2. “那要不要去做检查”

`a_not_a` 只在三种位置承认“要不要/用不用/需不需要”是正反疑问：

- 小句开头；
- 主语（你、我们……）之后；
- “关于、想知道、确认”等框架之后。

句首的“那”不在其中，所以“要不要”中间的“不要去做检查”被当成劝阻就医。

r8 只在这个主语位置之前允许一个连接词（那么 / 那 / 所以）。仍然要拒的写法都有测试：

- 那不要去做检查了；
- 那就不要去做检查；
- 那只要不要去医院就行（跨词重复）；
- 那要不要紧都不要去医院；
- 那要不要去做检查？那不用去医院。

## 3. 否定“稳赚”的宾语

r7 的 `GAIN_DISMISSAL` 只认固定宾语：配合、合作、投资、收益、回报、这笔投资、这次合作、它、这。r8 的规则如下。

**宾语（`GAIN_OBJECT`）：**

- 1–10 个汉字，可带中文或英文引号；
- 宾语里不能有否定或转折字（不、没、非、无、别、但、而、却、是），也不能有确定性用语或另一个“稳赚”（必、一定、肯定、注定、铁定、绝对、百分、毫无）；
- 所以宾语里藏不进第二个小句或双重否定。

**谓语：** 原有的当、当作、当成、视为、看成、看作、理解为，加上理解成、误解为、误认为、错当成；谓语后允许引号。

**续文（`GAIN_DISMISSED_REST`，新增）：** 豁免的“稳赚”后面只能是小句结束（可带引号、语气词），或“的事 / 机会 / 买卖 / 生意 / 保证 / 承诺 / 信号 / 理由 / 依据 / 把握”。

- 在 `da447c4` 上，“别把配合当稳赚以外的选择”能通过，它的意思是只选稳赚，属于肯定；r8 拒。

**负责人已有的守卫全部保留，照旧通过：**

- 这笔投资稳赚；
- 转折后重新肯定；
- 不得不 / 不能不 / 不是不；
- 别把配合当机会这笔投资稳赚；
- 必涨、必死、必然确诊照旧硬拒。

**新增的仍须拒：**

- 不得不把一时的配合顺畅当成稳赚、不是不把顺手当稳赚：双重否定加长宾语；
- 别把不赔当稳赚、别把一定会涨当稳赚：宾语带否定或确定性用语；
- 别把顺手当成稳赚的反面、别把“配合顺”误解为“稳赚”以外的东西：续文；
- 别把它当稳赚，它就是稳赚；别把一时的配合顺畅当成稳赚，但这笔投资稳赚；别把配合当机会而这笔投资稳赚；别把握机会，稳赚：每处“稳赚”各自判断。

## 4. 手写相位的闭集（复核发现）

`DAILY_SYSTEM` 要求相位只写编号，但代码没有核对手写的相位：

- `Daily.problems` 不看相位；
- `plugins/astro/validation.py` 读不出“X与本命Y的三分相”和并列写法。

在 `da447c4` 上，写当天并不存在的“月亮与本命冥王星的对分相”，0 次修复就提交了。

**r8 的 `ASPECT_CLAIM`：**

- 读行运写法：（行运）X 与/和/对（本命）Y（、Z……）（的/形成/呈）合相/对分/四分/三分/六分（相）；
- 并列的每个本命星都要和行运星、相位一起，对上当天的某个事件，否则要求改写，并提示只写编号；
- “本命X”开头的写法不是当天的行运，不在这里核对。

写对的手写相位照常放行（测试：月亮与本命木星的对分相、行运水星与本命木星六分相）。代码不替手写相位补 evidence，是否补由负责人决定（[复核 §4](../pilot-r7/review.md)）。
