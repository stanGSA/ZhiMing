# p2-final：编造失败的离线分类依据

由 Codex 阅读原始回答、结构化字段、计算事实和评委理由分类；没有另行调用评测模型，也没有独立人工裁决。保留原始 `no_fabricated_facts` 评分。[fabrication-reviewed.yaml](fabrication-reviewed.yaml) 是 `quality_reasons --reviewed` 的分类输入，表格中的“完整”仅描述评分与分类覆盖。

事实类指可核对的计算数据或引用错误；叙述类指将个人经历、习惯、场景或预言当作已知内容。只分类编造维度对应的失败点，不把其他维度的时间或论证错误自动追加为事实类。题号 `#1/#2/#3` 对应 `repeat=0/1/2`。

## 计数边界

上述四条均成功提交。失败总数 4，事实类 0、叙述类 4，无两类重叠；这是对已被评委判为编造失败的条目进行分类，不证明其他回答不存在编造。每日单模型另有 `daily_final_overall#2` 未评分：评委两次返回不可解析 JSON，原始回复见 [unscored-reviews.json](unscored-reviews.json)，不能将其计为没有编造。

因此每日单模型的叙述类占已提交答案比例须保持区间：4/12 至 5/12，即 33.3%–41.7%。`--reviewed` 关闭了四条已评分失败的分类待定项，但不会关闭这条评分缺失。原始诊断及完整回答见 [quality-reasons-with-answers.md](quality-reasons-with-answers.md)。
