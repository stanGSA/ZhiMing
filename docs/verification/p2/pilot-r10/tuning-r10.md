## 2. 范围与守卫

**冒号：**

- 只放宽“共同主语 +（冒号或逗号）+ 都”；
- 没有“都”时，“两个名字：外格2”仍不绑定；
- 前置否定（并非两个名字：都……）仍不绑定；
- 主语后面又写出全名时，后面的数值归那个名字；
- 数值仍要对每个名字逐一核对。

**来源短语：**

- 只绑定这一个完整短语（去世的奶奶），而且只在 `matcher.spans` 恰好给出一个覆盖全句的别名时才绑定；
- 由多个意象组成的短语（猫和蛇）不绑定，沿用 PR #46 的守卫；
- 另一个意象的其他别名（去世的亲人、去世的爷爷）仍是未命中；
- 只在流水线里生效，单 agent 校验器不继承。

**己：**

- 只认“自己”这一个词；
- “己申年”“今年是己未年”“自庚子年起”“你的日柱是庚子”这类没算出来的干支仍拒。

**三者：**整词豁免；“地格三”“地格3”仍拒。

**算式：**

- 结果写错（得19）、主语格对不上（人格由……得18）、和算错（天格加地格得42），都拒；
- 算式之后另写的“人格18”照常单独核对。
