## 4. 为什么在新口径下误拒仍然阻断

新口径下，只修复一次就通过的误拒不阻断，造成降级的才阻断。r10 的 3 条误拒都在两稿后降级。

原因在修复请求里。`pipeline/compose.py::repair_messages` 只列出问题描述，没有引出触发它的那句话。比如：

- “不能把梦境说成现实事件的预兆”；
- “陈思远的数理1与本次计算不符”；
- “不能给出健康、投资或生死的确定性结论”。

规则误拒时，模型看不出自己的哪句话违规，往往只改别处，保留原句，于是第二稿又被拒。r6 到 r10 因误拒导致的 11 次降级（2、4、1、1、3），修复稿都保留了同一个触发写法。

反过来，问题描述里点了名的，模型基本一次就改对了，比如：

- “‘画’不是本次命中的意象”；
- “外格2须写明是哪个名字”。

所以除了修这三处单点之外，r11 改了修复请求本身，见 [../pilot-r11/tuning-r11.md](../pilot-r11/tuning-r11.md)。
