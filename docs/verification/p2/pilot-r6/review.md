## 6. 需要负责人确认

1. **“稳赚”在否定句里的处理。** r7 只在每日运势的撰写提示里加了一句：“稳赚、必涨、必死、必然确诊”即使用在否定或提醒里也不要写。`HIGH_RISK_CLAIM` 和 `policy_judge.HARD` 的语义没有改，否定句照样拒，也照样计入两稿安全降级。是否把“别当稳赚”这类否定改为放行？这属于改共用安全规则的语义，请负责人决定。
2. **“奔跑”与“被追”的绑定范围。** r7 只在以下条件下把词典别名“奔跑”算作命中的“被追”：
   - 命中了“被追”；
   - 没有命中“跑步”；
   - 用户原话在同一小句里是“被……追（着/得）+ 至多一个副词 + 跑”。

   “跑步”本身从不绑定。复述时的自由写法，如“一直跑”，仍按事实表外内容检查（现有测试“你梦里一直跑，这个画面说明你想逃开什么”仍拒）。如果负责人认为“奔跑”也应该只在复述时放行、解读时仍拒，请指出。
