## 3. 修复引句的效果，以及唯一的降级

- 11 次修复中，9 次修复请求引出了触发句。这 9 次都一次修复成功，没有降级，被引的整句也都没有原样留在修复稿里。
- 唯一的降级是 Dream `chased_to_exam#1`。它的修复请求没有引句，原因是：
  - 这条规则是跨句判断的。前一句复述梦里的细节，后一句用“这个转折说明……”承接并解读；
  - 两句分开检查都能通过，连在一起才被拒；
  - 而 r11 的定位器只逐句检查，所以找不到触发句。
- 这一条本身属于按设计拒。`DREAM_SYSTEM` 明确要求不要用“这个画面、这种场景、这说明”去承接事实表没有的细节，而原稿正是用泛指主语解读了未收录的“没准备、考场”。所以它不是误拒，不算造成后果的可定位误拒。
- 不过缺少引句是定位器的缺口：r12 在单句找不到时，会再试同一字段里相邻的两句，并已用这条原文写了测试。

single 组、只修复一次的误拒，以及流水线里修复一次就成功的误拒，都按口径记录，不阻断：

- Name-pipeline：“不能据此说你一定会遭遇什么”；
- Dream-pipeline：“比担心梦的预兆更有用”“梦里逃跑的终点”；
- Dream-single：“不是任何现实事件的预兆”。

## 4. 审查 F1–F4（已在 PR #53 上修复）

审查里的每个反例都写成了测试，在 `cff1f61` 上失败、在修正版上通过：

| 编号 | 问题 | 修法 |
| --- | --- | --- |
| F1 | “不可能没有预示 / 不能说这个梦没有预示 / 不是不提供预言”被当成否定 | “没有”和“不作/不提供”这类否定，都要先确认外面没有再套一层否定：用共用的 `denial_negated`，加上“不可能、不会、未必、不见得、难说”，中间可以隔一个短主语。“不是X的预兆”里的修饰词也不能是否定字（“不是不作预兆解读”仍拒） |
| F2 | “阳性上升 / 阴性上升”因为前一个字是“性”被豁免 | 改为只认完整的数量词（活跃度、人气、信心、压力、收入……）加上升；只看前一个字的写法删除 |
| F3 | “点”的通用豁免放过了“人格二十四点五” | 只豁免完整的“一套、一些”，以及后面不接数字的“一点”；格数和数理后面接小数一律拒绝，整数部分对也一样（“人格二十五点五”） |
| F4 | 去尾逗号时连字符串里的“,}”一起删掉 | 改为逐字扫描，跳过字符串和转义；修补成功的行同时保存原始回复（`unrepaired_reply`） |
