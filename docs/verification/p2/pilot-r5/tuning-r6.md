## 2. 解梦：“找不到出口”就是命中的“迷路”

**依据：** 词典里，“找不到路”本来就是“迷路”的别名，“迷路”的一般含义也写着“在具体地点找不到路、无法辨认路线”。“找不到出口”“寻不着出路”“出口难找”是同一个构式，只把“路”换成了“出口、出路、方向”，这些词都不是词典里的意象。

**修法：**

- `plugins/dream/validation.py::OUTPUT_NORMALISATIONS` 加上“迷路”的构式：
  - （到处/四处/一直）找不到/寻不着 + 出口/出路/方向/路；
  - 出口/出路 +（很/太/总/也/都）难找/找不到。
- `pipeline/dream.py::Dream.unlisted`：本次命中了“迷路”，才把用户原话和撰写稿里的这个构式算作命中的意象。没命中“迷路”时，这个构式仍按事实表外的内容处理。
- 只在流水线里生效（`unlisted` 本来就只在流水线里用）。

**和 r3 归因的出入，请负责人确认：** r3 把 `dream_lost_in_mall#3`（“找不到出口……对应到心里，可能是对下一步往哪走还没有答案”）判为“按设计拒”；r1 时我写的一条守卫测试也要求命中“迷路”时拒绝“到处找不到出口，往往反映你对方向的困惑”。r5 负责人把同类写法判为误拒，本 PR 按 r5 的判定执行：

- 这条旧守卫改为“没命中迷路时仍须拒”；
- 如果负责人的意思只是“复述放行、解读仍拒”，请指出，我把构式改成只在复述时放行。

## 3. 姓名：单字数字夹在词里，不是格数

r5 姓名流水线有 4 次修复、4 次降级，每次都是两稿报同一个问题：赵杰“数理1”2 次，比较题“外格2”1 次，林晓“外格22”1 次。

这类问题的原文没有引号，`pipeline_problems` 列不出原句，所以我没法确认原稿是怎么写的。但在 `a609baa` 上离线复现，以下常见写法都会这样报：

| 写法 | 被读成 |
| --- | --- |
| 数理一般、数理一致、数理一说、数理一共 | 数理1 |
| 外格二者、外格两相比较、外格二人 | 外格2 |
| 人格十分重要 | 人格10 |

**修法（`plugins/name/validation.py::CLAIMED`）：** 单个中文数字后面紧跟另一个汉字时，是词的一部分（一般、一致、二者、十分），不算数值；后面是标点、“吉、凶、的”或文末时，照常核对（“总格五，”“人格五吉”“人格五的含义”）。多字数字和阿拉伯数字不受影响。

“林晓的外格22”是阿拉伯数字，这次不改。如果它是误拒，下一轮原句会列出来。

**可见性：** `scripts.pipeline_problems` 遇到没有引号的姓名问题，改为按问题里的格名或“数理”列出候选句。下一轮姓名的修复也能看到原句。
