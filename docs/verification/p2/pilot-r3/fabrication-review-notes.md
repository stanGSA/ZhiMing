# r3 编造分类复核依据

本轮由助手按用户要求复核合成题证据，不代表新增人工校准。原始评委结果全部保留，没有通过重新请求模型或改布尔值提高分数。分类对象仅为已提交且四维已评分、`no_fabricated_facts=false` 的回答。分类为事实类并不要求评委恰好在该字段的理由中承认数值错误；同时核对原答和确定性事实，避免漏掉 UTC/当地时间错用。一条可以双重分类，失败总数不重复计。
