# 姓名流水线 r3：修复归因

`name_compare_two#1` 首稿拒绝：`“張”不属于李娜，笔画不能串用`。

原句：

> 两者笔画都按康熙字典繁体字形计，如张作張11画、伟作偉11画，李7画、娜10画，与现代简体笔画可能不同。

这四个笔画数与本轮计算相符，没有把错误的数值作为事实提交。该段前一句依次谈张伟、李娜，最近的完整姓名是李娜；`plugins/name/validation.py::check_claims.owner`按同一字段内最近的完整姓名绑定断言，因此把后面的張绑定到李娜。撰写约束要求有两个姓名时每处写清归属，草稿使用“两者”后仅列单字，没有重新写完整姓名，触发了这一规则。

语义上读者可以区分两人的字；字段级的最近姓名规则比这种并列表达更严格。这里记为现行归属契约触发的修复，不能说数值算错，也不能仅凭错误文字断言发生了串名。后续若要支持这种表达，需要明确归属策略并保留拒绝真正串用笔画的守卫。修复后的本条通过原评委评分，未降级。
