## 编造与质量失败

[`--reviewed`计数表](fabrication-counts.md)中，仅Daily-single存在编造失败：7条，其中4条兼有事实类错误，7条均涉及叙述类，叙述占已提交41.2%。一条双重分类仍只算一次失败。其他五组编造失败均为0。

分类由助手在用户要求下结合原答、评委理由及计算事实复核，不代表新增人工校准。没有更改原评分。表中“完整”表示没有未评分或未分类的已提交回答，不表示所有回答都正确，也不表示评委经过独立验证。可核验的时间错误即使被评委漏判，也在[分类备注](fabrication-review-notes.md)中说明。

Daily-pipeline保留原质量16/18，两条失败均未修复或降级：

- `daily_today_general#3`仅时间失败。原文准确区分当地00:00–23:00和23:00–24:00，评委先认可换算，再以UTC起点位于前一日为由否定当天主题，混淆了时区。
- `daily_lucky_color#3`时间和支持性失败。当地两段完整覆盖当天；水海、月木相位均在当地当天。评委声称命运之轮逆位不支持替代路径，但实际所引释义明确写“适合稳定日常安排并准备替代路径”；三会释义也明示力量集中，原文没有断言成格。进一步建议与整体措辞仍可讨论，保留原失败，不以复核替换分数。

全部24条质量失败（含single未提交故障回答）的逐条归因见[质量复核](quality-attribution.md)。解梦single有5条retry_limit、1条步数上限、2条追问；姓名single有4条retry_limit、3条追问、2条text终态；Daily-single有1条retry_limit。任务完成、已提交、工程通过及质量通过分别统计，不能把追问评分通过算成已提交解读通过。特别是Daily-single提交17条，但只有11条满足任务完成检查，见[完整对照](comparison.md)。
