# PR #7 合并后的校验修复

PR #7 已通过合并提交 `12132492f5c807803399354b24e637c6f9c5bf72` 进入 main。本修复以该提交为基础，处理第二轮评审中确认的回归与漏检。

## 修复内容

1. **相位事实归属**：显式标注的“本命／行运”优先于段落引用提供的默认语境。行运事件不能证明一个本命相位；同句包含本命与行运时逐组核对，不再把整句都视为行运。摘要、依据中的显式本命声明也按本命盘检查。
2. **日期关联**：保留逗号前的日期引导语，绑定到紧随其后的相位；识别“发生在／发生于”等相位续写。保留本地／UTC 日期区分，不把寒露换月说明或用户另行安排的行动日期当作相位日期。切换到本命关系后清除上一个行运事件的续写上下文。
3. **就医表达**：拒绝“不建议就医”“不应就医”“不需要马上就医”等否定建议；“不要以为不必就医”等对劝阻说法的否定不再误拒。缺少可见求医建议时继续自动补充提示。
4. **确定性表达**：“并非你一定会失败”允许主语位于否定词和确定性词之间；遇到“但／然而”等转折时结束前一个否定作用范围，防止肯定断言借用前文否定绕过检查。
5. **对照统计**：保存拒绝的原始错误码和信息，分别统计事实、表达、安全、schema、审校及其他拒绝。审校重写不再混入事实错误。无法识别的旧记录明确列为未分类；保留实际返回的模型名及代码版本信息。运行结束关闭模型客户端。

上述文本识别仍是针对已支持中文表达的确定性规则，并非通用自然语言理解器。回归测试同时包含应放行与应拒绝的语序、标点和否定变体，以避免只修补单个示例。

### 人工阅读与失败归因

- **八字月运与补水追问**：新版 single 首轮呈现四层分析，结合用户明确提供的研究生、多智能体项目和压力背景，解释原局、财杀关系、辰戌冲和支持资源，再落到实验范围、反馈和休息安排。追问通过 `read_reading` 接续，没有重算；既说明壬水亥月不宜直接判断缺水，也给出蓝黑物品、安全的水边散步、水声和收工仪式等低成本建议。正文出现身体话题时带有可见求医提示。
- **换实习与本命占星**：新版包含作用关系、现实挑战、具体策略，建议核实带教、验收条件、权限与资源，不再主要由逐条依据撑起篇幅。多 Agent 的本命占星中间报告出现过宫位错误，校验器拦截后改写；这计为一次事实拒绝，不能当作最终回复仍有该错误。
- **塔罗与连续追问**：新版两种模式均沿用原有月亮逆位、正义逆位、高塔正位，追问没有重新抽牌，能解释第二张牌与工作场景的联系，并给出可直接使用的沟通问法。不同模式首次选择的牌位语义不同，因此只比较是否沿用各自原牌阵，不把两次文字当作完全相同牌位条件下的实验。
- **个人偏好仍可能被推定**：新版 single 二选一写出“你的稳定诉求”，但用户仅说 A 公司稳定，并未声明自己偏好稳定。这是人工阅读发现的残余问题；事实校验器通过不代表每一句关于用户的判断都准确。
- **跨月区间存在重复追问**：首题“这个月（2026年10月8日到11月6日）”在新旧运行中均触发过“计算日期范围必须与用户明确指定范围一致”。脚本仅自动补答一次出生资料，无法代替用户解决日期歧义；仍为 `ask_user` 的记录不计入完成。新版 single 经重试完成，但其他失败首轮后的补水回复不能作为“成功首轮后的正常连续追问”证据。
- **多 Agent 行运预算不足**：新版 multi 的占星行运最终为 `limit_reached`，没有提交解读。默认 `compute_transits` 返回 109 个事件，专家后续调用预算被拒，重复咨询仍未完成。旧版同题也曾出现相同预算拒绝，但随后改为计算 Mars/Jupiter/Saturn/Uranus/Neptune/Pluto，返回 4 个事件后完成。因此该风险在改造前已存在，本次不能证明新版多 Agent 的完成稳定性更好。
- **多体系题未完整交付**：新版 single 在计算完成后的模型调用中发生 `APITimeoutError`，该回合耗时 308.72 秒，最终为 `model_error`；不把它算作校验拒绝，也不凭一次超时归因于校验代码。新旧 multi 均因占星专家预算不足只交付八字；新版在可见摘要中明确说明未形成占星交叉结论，这是合理披露，但仍未完整满足问题。
- **每日运势**：新版两种模式均有三层正文和具体行动，区分相位精确时点与现实行动安排，没有把精确节点直接当作全天吉凶窗口。相较旧版内容更充分，但篇幅和耗时也增加，是否需要短版入口仍属于产品取舍。

本次修复范围是第二轮评审确认的事实归属、日期绑定、否定表达和统计口径问题。上述实测发现的日期需求识别、上下文预算与用户偏好推定保留为后续改进项，不因已有回归通过而宣称完整产品质量验收通过。
