# PR #7 合并后的校验修复

## 修复内容

1. **相位事实归属**：显式标注的“本命／行运”优先于段落引用提供的默认语境。行运事件不能证明一个本命相位；同句包含本命与行运时逐组核对，不再把整句都视为行运。摘要、依据中的显式本命声明也按本命盘检查。
2. **日期关联**：保留逗号前的日期引导语，绑定到紧随其后的相位；识别“发生在／发生于”等相位续写。保留本地／UTC 日期区分，不把寒露换月说明或用户另行安排的行动日期当作相位日期。切换到本命关系后清除上一个行运事件的续写上下文。
3. **就医表达**：拒绝“不建议就医”“不应就医”“不需要马上就医”等否定建议；“不要以为不必就医”等对劝阻说法的否定不再误拒。缺少可见求医建议时继续自动补充提示。
4. **确定性表达**：“并非你一定会失败”允许主语位于否定词和确定性词之间；遇到“但／然而”等转折时结束前一个否定作用范围，防止肯定断言借用前文否定绕过检查。
5. **对照统计**：保存拒绝的原始错误码和信息，分别统计事实、表达、安全、schema、审校及其他拒绝。审校重写不再混入事实错误。无法识别的旧记录明确列为未分类；保留实际返回的模型名及代码版本信息。运行结束关闭模型客户端。

上述文本识别仍是针对已支持中文表达的确定性规则，并非通用自然语言理解器。回归测试同时包含应放行与应拒绝的语序、标点和否定变体，以避免只修补单个示例。
