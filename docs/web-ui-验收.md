# 网页出生地点、排盘与功能主题验收

日期：2026-10-15。

## 问题与修复

1. 原 GeoNames 城市快照没有临泉县，新增中国行政区层级与县区中心坐标。浏览器逐级选择地点，服务端按地点 ID 取得规范名称、坐标、时区；不替换成附近城市。
2. 原网页把日期与时刻用分号隔开，后端证据解析器刻意不把另一句的时刻拼到日期上。现在将同一表单的日期时间序列化在同一句内，保留原有校验规则。
3. 新增独立历法/星历排盘入口，不依赖模型猜测基础盘。模型仍通过已有工具计算、校验、提交解读。
4. 八字、占星、塔罗分别使用暖金四柱、深蓝星图、紫金牌阵；切换栏目后显示对应的引导与本栏提问。塔罗不发送出生资料，牌阵选择传入真实抽牌流程。

## 验证

- 完整离线测试：**308 passed**；Ruff 检查与格式检查通过。
- 浏览器：国家→省→市→县选择、上级变化清空下级、临泉县排盘、未知时辰、刷新后恢复、占星图、单张牌阵、海外城市精度标注、三种主题切换。检查 1440 / 1024 / 768 / 760 / 390 / 360 px，未出现横向溢出；无浏览器脚本错误。
- 真实配置模型验证：使用明确标记为合成测试的资料（2001-11-25 10:11、临泉县、男、不用真太阳时、23 点换日）。首次验证暴露日期时间分句问题；修复后约 37.4 秒完成，状态为 `submit_reading`，没有换城或再次要求日期确认。
- 返回事实：辛巳年、己亥月、壬辰日、乙巳时，日主壬水；与网页确定性排盘一致。此验证只确认接入与排盘事实，不证明主观命理解读的现实预测能力。

## 范围

国内区县与海外城市的覆盖、数据来源和精度见 [数据说明](../common/region_data/README.md)。区县坐标是行政区中心；不是具体医院定位。国外没有区县层级时明确注明市级地点，不伪造下级地址。未知时辰不显示时柱、上升和宫位；新疆保留出生钟表时间制确认。

当前仍是本机、单进程会话；服务重启会开启新身份。测试输出和界面截图位于被 Git 忽略的 `reports/web-browser/`。
