# 账号免费额度与 IP/设备注册限制上线记录

2026-10-30（北京时间），已部署到 [https://zhiming.mom](https://zhiming.mom)。基线仍为 `8be21c0`，保留公开访问和账号权限补丁，新增发布补丁 `lifetime-free-quota-and-ip-device-registration`。既有账号、18 条解读及生产模型配置保留；本次没有真实模型调用，没有在生产注册测试账号。

## 生效规则

- 每个账号累计免费 **250,000 Token**，不按月重置。输入与输出合计，缓存输入照计；输出已包含的思考 Token 不重复计算。网页各功能、编排者、专家、审校与辅助安全判别共用一个账号额度。
- 上线时的 1 个已有账号获得完整 250,000 Token，以前的用量不追溯。历史注册缺少来源设备记录，不重建、推断此前的 IP/设备关系。
- 调用前原子预留输入估算和输出上限，模型返回后按实际用量结算并释放多余预留。每次 HTTP 重试单独记账，额度不足时在发请求前拒绝。输入预留使用包含工具定义的 UTF-8 字节数加协议余量，较实际 Token 数保守，余额仍大于零也可能不足以容纳长上下文；厂商返回用量是最终依据，厂商隐含协议开销无法得到绝对上界保证。
- 已知的请求拒绝不扣额度；超时、取消或缺少用量时按该次预留量保守记账。崩溃中断留下的预留跨重启保留，不自动清零，管理员应结合厂商记录核对 `model_usage` 中的 `reserved`、`uncertain` 状态后再人工处理，避免重复调用导致超用。
- 余额在页眉与账号菜单显示，删除解读、清空记录、退出登录及重启不会重置。额度不足仅限制新的模型调用，离线演示、直接排盘和历史访问仍可使用。
- 同一 **IP + 设备** 组合在滚动 **7×24 小时** 内只能成功注册一个账号；不同设备共用同一 IP 可分别注册。事务中再次校验，拦截并发注册；注销账号仍保留剩余窗口，注册资料转入失败则撤销新账号和对应限制，允许重试。

设备身份使用服务器签名的随机浏览器 Cookie `zhiming_device`，HTTPS 下具备 Secure、HttpOnly、SameSite=strict 属性，有效期一年。数据库仅存来源 IP 与随机设备身份组合的 HMAC，不存这项限制的明文 IP，过期注册限制在正常清理中删除；Nginx 自身访问日志仍按原策略保留。设备签名密钥持久保存在业务库，不写入浏览器或发布记录。

**识别边界：这是浏览器设备标识，不是物理硬件识别。清除 Cookie、无痕窗口、更换浏览器都可能取得新身份，更换 IP 也会形成新的组合，不能保证阻止所有重复注册。** 没有新增邮箱、短信或硬件指纹验证。隐私说明版本更新为 `2026-10-30`。

## 部署和数据保护

先执行系统备份，再对 SQLite 一致性副本演练迁移，对比账号、解读、追问、生辰与画像表的完整快照。迁移只新增 `account_quota`、`model_usage`、`registration_devices`、`account_settings` 表及必要索引，不更改业务 schema 5；已有账号初始化额度统计。正常注销时额度和用量随账号删除，注册限制不级联删除。

部署核对旧文件与上传文件 SHA256 后短暂停应用，保存最终一致性数据库副本，再替换 11 个应用文件及 2 份代理配置。生产数据库迁移由应用用户执行。Nginx 将 `X-Forwarded-For` 覆盖为 `$remote_addr`，不接受公网调用方伪造的转发链；应用仅使用 ASGI 客户端地址，结合原有只信任本机反代的配置。当前没有额外 CDN 层，如新增 CDN 需重新配置可信代理来源。

应用文件为 `app.py`、`web.py`、`memory/accounts.py`、`harness/llm.py`、`harness/failures.py`、新增的 `harness/metering.py`，以及 `web_static/` 中的 `app.js`、`base.css`、`login.html`、`login.js`、`privacy.html`。逐文件 SHA256、验证结果和补丁标识写入服务器 `/etc/zhiming/release.json`，未上传模型凭据或本地配置。

## 回滚

发布脚本在部署或核验异常时会停止应用、恢复代码与代理配置、恢复发布元数据、检查并重载 Nginx 后启动旧代码。只回滚代码时保留新增数据库表，旧代码会忽略这些表，既有业务记录无需覆盖；**回滚旧代码会停止执行本次额度与注册限制**。线上产生新用量后，不应直接覆盖为部署前数据库，否则会丢失期间记录和扣账；如需回退，应先保存当前一致性备份并明确恢复点。

本次未改动证书、定时备份、生产模型密钥或独立模型配置；证书正式续期网络限制及既有模型质量状态见[当前部署说明](../deployment.md)。
