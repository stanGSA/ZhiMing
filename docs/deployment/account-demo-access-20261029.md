# 2026-10-29 账号登录优先与访客离线限制

正式网站 https://zhiming.mom 已按用户要求调整：入口默认显示账号登录；保留访客入口，访客仅提供离线演示；只有注册、登录个人账号后才能调用大模型。已登录账号仍可直接回到问道页。访客再次打开首页时显示登录入口，手机和窄屏将登录表单排在罗盘介绍之前。

## 实现与部署

访客创建会话时服务端始终选择 `demo`，包括直接访问功能页及请求 `provider=configured`；访客请求 `/api/new` 切换真实模型返回 403 和 `account_required`。运行时构造前再次验证用户属于账号，通用会话读取及重建对话路径也验证身份，覆盖模型解读与模型参与的安全判断。账号恢复时正常使用配置模型，退出后的新会话强制离线。

前端默认选中账号登录标签，访客页只有「进入离线演示」入口；七个功能页共享脚本依据账号身份隐藏并禁用真实模型选项。注册、登录后恢复账号记录与真实模型访问；访客记录迁入机制保留。

在 `8be21c0` 加取消共享口令补丁的基础上，仅更新 `web.py`、`web_static/login.html`、`web_static/login.js`、`web_static/app.js`、`web_static/theme-login.css`。部署前核对旧文件哈希、执行一致性备份，保存原文件后原子替换并重启应用。未覆盖业务库、模型配置、启动器、Nginx 或证书。

服务器 `/etc/zhiming/release.json` 的 `local_patches` 新增 `account-only-model-access`，保存实际文件 SHA256。部署证据与回滚文件位于 `/var/lib/zhiming-deployment/account-demo-access-20261029/`；本地操作材料在忽略目录 `reports/account-demo-access-20261029/`。
