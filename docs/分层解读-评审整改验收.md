## 二、真实模型对照（第 5 项）

### 对照工具

`scripts/compare_layers.py` 固定以下条件：

- 10 个问题：八字时机及“这个月值得关注什么 → 具体怎么补水”的连续追问、八字时机、占星本命、占星行运、三张塔罗及追问、二选一、八字+占星时机、每日运势；
- 合成出生资料：2001-11-25 10:00 北京，即参考答案中的“辛巳 己亥 壬辰 乙巳”；
- 用户背景：研究生、多智能体项目、压力大，用来检查是否使用用户给出的背景；
- 咨询日期范围、日历基准 2026-10-15、塔罗 seed 42，以及同一个模型名。

同一脚本可以分别对旧版（`main`）和新版检出、单 Agent 和多 Agent 各跑一遍：

```bash
git worktree add ../zm-old main
python scripts/compare_layers.py run --root ../zm-old --data-from . --label old --mode single --model gpt-6.1-sol
python scripts/compare_layers.py run --root .         --label new --mode single --model gpt-6.1-sol
python scripts/compare_layers.py run --root ../zm-old --data-from . --label old --mode multi  --model gpt-6.1-sol
python scripts/compare_layers.py run --root .         --label new --mode multi  --model gpt-6.1-sol
python scripts/compare_layers.py report reports/compare/old-single reports/compare/new-single \
  reports/compare/old-multi reports/compare/new-multi --output reports/compare/report.md
```

每次运行在 `reports/compare/<版本>-<模式>/` 下保存每题的完整回复与结构化输出（`replies/*.md`）、全部 trace（`traces/`）和 `results.json`。

报告给出以下数据：

- 回复字数、正文字数、依据占比、分层数；
- 提交次数与被事实校验拒绝的次数、专家报告被拒次数；
- 审校结论、warnings、追问是否重算或重抽；
- 每题的人工检查清单：作用关系 → 挑战/机遇 → 应对、承接前文、使用用户背景、不编造、就医提醒与确定性措辞。

## 三、个性化记忆的范围（`life_context` 未实现）

- **会话内**：用户在当前对话里说的背景（职业、在做的项目、近况）随消息历史提供给模型。提示词要求模型用这些背景把建议落到具体场景，不编造用户没说过的个人事实。
- **跨会话**：画像只保存出生资料、体系偏好等字段，以及最近记录的结论摘要；**不保存职业、近况等生活背景**，新会话里模型不会记得这些。
- 需要跨会话记住背景时，再按原计划加 `life_context` 字段：只保存用户原话、可查看可删除，并纳入 `/forget`。
